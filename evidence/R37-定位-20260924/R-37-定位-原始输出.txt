=== ③ 改法（注入版实测通过；真实现按这 4 处落）===
  A. talk.js:934-937（抬头 .tk-title）：加 head.style.cursor="pointer"; head.addEventListener("click", () => this.openRoleSheet(r.full_name));
     —— 主入口：最大、语义最对（"这个角色"的信息），远离气泡正文，不与将来任何气泡内行为抢。
  B. talk.js:1041-1058（paintChat 的 items.forEach）：**非本人**那支加
     if (!me) { bu.setAttribute("data-from", r.full_name); bu.addEventListener("click", () => this.openRoleSheet(r.full_name)); }
     —— 与群聊同构（talk.js:676-680）；注意单聊这里填的是 r.full_name（不是 m.from，items 里没有这个字段）。
  C. talk.js:1060-1064（live 追加的那批，永远是他发的）：同样挂一份。
  D. 守卫（**必须有**，见 ⑤ 负向 3）：touchstart 记坐标 → touchmove 位移 > 8px（或按住 > 500ms）置 _drag=true → click 里 if (this._drag) return;

=== ④ 冲突检查（逐条给结论）===
  · 长按复制 / 选词：**不冲突** —— 气泡是纯 div，body { -webkit-user-select:none; user-select:none }（style.css:43-44）本来就弹不出选择菜单；
    click 与长按是不同事件，挂 click 不会抢长按。⚠ 反过来：**以后若想让气泡能选中复制文本**，就得把"可点区"收到抬头那一行。
  · 点链接：**不冲突** —— 气泡正文是 textContent（talk.js:1049），DOM 里没有 <a>；将来若加链接，click 里先 if (e.target.closest("a")) return; 放行。
  · 抽屉 / 边缘手势、滚动：**不冲突** —— 只挂 click，**不碰 touchmove、不 preventDefault**（实测见负向 3：拖 80px 后滚动照常）。

=== ⑤ 三条负向（真触摸实测）===
  1) 点**本人**气泡不该开：只有 him 挂监听、me 不挂 → 窗在 = False ✔

  3) **滚动手势**不误触：在他人气泡上按住拖 80px → 窗在 = False ✔；scrollTop 62568 → 62633（滚动照常），守卫记到位移 = True ✔
