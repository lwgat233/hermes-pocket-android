== 本次我改了什么（两个文件）==
1) `assets/ui/talk.css`：新增
   `#tk-chat { padding-bottom: calc(var(--sayline-h, 68px) + var(--safe-b, 0px) + 8px); }`
   —— **内层滚动容器**（单聊页那个 `#tk-chat`）留出「粘性条高 + 安全区 + 8px」。
   · 选择器用 **`#tk-chat`**（id）而不是 `.tk-chat`：群聊页那条流只是 `class="tk-chat"`、里面没有粘性条，
     不该被加空档（第一版我写成 `.tk-chat`，会让群聊流底部多 68px 空白，已改掉）。
   · **没动外层 `.panel-body`**（甲案按作者实测更糟：重叠变 93px）。
2) `assets/ui/talk.js` · `paintRole()`：粘性条 `#tk-sayline` 挂进页面后量一次高度，写进 `:root` 的 `--sayline-h`
   （`noteH()` 立刻量一次 + `requestAnimationFrame` 布局稳定后再量一次；量不到就用 CSS 里的 68px 兜底）
   ⇒ **不写死数字**，字号/安全区一变不会失配。
3) **共用规则**（经理口径，已进 SPEC §10）我按同一写法落实并留在注释里：
   **凡「粘性/固定底部条」，上方滚动内容必须留 `calc(条高 + var(--safe-b))` 的底部内边距** —— ⑥讨论 B 案（频道页自带输入条）落地时照这条来。
