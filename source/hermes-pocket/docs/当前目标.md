  先证明「设备跑的是这一版」（页面里有版本标记/渲染计数），再谈逻辑。
- **一轮一个功能点**，只测改动范围；全量回归是发布前的事。

## 5. 环境备忘（本轮踩到的）

- 宿主上跑的模拟器在容器 `notifbridge-emu` 里（`docker run … emulator -avd test35 -port 5554`，
  启动命令原件在归档 `env/emu.sh`、`env/容器启动命令.txt`）。
  **起/重建容器要用户批准**：本轮 `docker rm -f` + `docker run` 被安全策略拦下（未重试）。
- 已实测：模拟器 guest 被卡死时 `adb shell` 会**永久挂住**（`echo ok` 两分钟不回），
  `adb emu kill` 报 `KO: unknown command` → 只能 `docker exec notifbridge-emu pkill -f qemu-system-x86_64` 收场（本轮这么做的，释放 2.8 G）。
- 构建（宿主即可，不用容器）：`JAVA_HOME=$HOME/tools/jdk-17.0.2 ANDROID_HOME=$HOME/tools/android-sdk gradle --no-daemon -Pkotlin.compiler.execution.strategy=in-process :app:assembleDebug`（本轮 15 秒）。
- **渲染层快迭代走本地测试台** `tools/ui-harness/`（Chromium + 假原生桥），不起模拟器也能读回真实 DOM 数值。
