## 2. 四个功能点（逐个：现象 → 真因 → 改法 → 读数）

### F-UI-9 设置「调了无效 / 保持不住」（log 第 9 条）— 已修

- **真因两个**：① 界面存了**两份状态** —— 设置面板改的是 `Panels.prefs`，终端读的是 `App.prefs`，改完只更新面板那份；
  ② `boot()` **先读偏好、后建通道**，`rpcRaw` 直接 reject → 落进 catch 只读到 localStorage 兜底值 → 每次冷启动所有设置回默认。
  另外双指缩放只改内存、不落盘。
- **改法**：`App.setPref(k,v)` 作唯一写入口（写内存 → 落盘 → 触发派生动作）；`Panels.prefs` 改只读转发 getter；
  `boot()` 顺序钉成「先 `connectTransport()` 再 `loadPrefs()`」；捏合结束落盘；设置页加一行回读
  「生效中：字号 20px · 终端 32×22 · 回滚 1000 行 · 已保存」。
- **读数**（`evidence/渲染与设置/F-UI-9-设置生效-原始输出.txt`，11 条断言全 true）：字号 13→24 当场 `term.options.fontSize=24`、
  computed `24px`、列数 50→27 真重排；重载后仍是 24；回滚上限改 1000 立即生效；开关立即生效；控件值与生效值一致。

### F-UI-1 长文本滚动 / 一键到底 / 缓存上限（log 第 1 条）— 已修

- **先复现**：普通缓冲其实能滚（300 行实测：下滑翻开 17 行 → 出现入口 → 点它回到最新、入口消失）。
  真正拉不动的是 **TUI（备用屏）**：本地没有历史，滚轮必须发给远端（tmux 默认没开鼠标）；
  而且滚上去**没有回程入口** —— 旧逻辑在备用屏里照普通缓冲算 `baseY-viewportY`，实测恒为 1，显示成没用的「上面还有 1 行」。
- **改法**：备用屏按"往外发了几格滚轮"给「⇣ 回到最新（TUI 里已往上翻 N 格）」，点它**反向发滚轮**把视图还回去；
  进出 TUI 时刷新入口文案；长按终端菜单加「⇣ 回到底部 / 最新」；远端没开鼠标时一次会话只问一次，不假滚。
- **读数**（`F-UI-1-长文本滚动-原始输出.txt`，12 条断言全 true）：普通 4 条（能往上翻 / 有入口 / 一键到底 / 入口消失）；
  备用屏 8 条（认出备用屏 / 认出远端鼠标 / 手势变成滚轮 / 入口文案对 / 一键回程又发滚轮 / 回程后入口消失 …）；
  另验"没鼠标"这条会弹出「开启 tmux 鼠标 / 取消」。

### F-UI-7 多个功能藏进左侧隐藏栏（log 第 7 条）— 已做

  **栏目由登记表生成**，抬头显示当前栏目，没做的栏目不摆出来。

### F-UI-11 加载完 skill 后很久才出聊天界面（log 第 11 条）— 已修（读数 + 策略）

- **读数**：启动打点六个阶段（`HP.BOOT`）：开始 74 / 通道就绪 75 / 偏好就绪 75 / 字体就绪 81 /
  **终端可显示 103** / 面板就绪 127 ms —— 终端**不等**面板与远端读取，能打字的时刻就是 103ms。
- **改法**：① 远端读取**不放在启动路径**（实测启动期间 `hermes.info` 调用数 = 0）；
  ② Hermes 页 60 秒缓存 + 同一次读取**去重**（`_fetchHermes` 记住 promise —— 以前点栏目和 renderAll 各读一遍）；

## 4. 测试方法（这轮新立的）

- 新增**本地测试台** `tools/ui-harness/`：用本机 Playwright 的 Chromium 直接打开 `assets/ui/index.html`，
  注入一个**假原生桥**（实现 `pref.* / host.* / session.* / hermes.*`），于是不起模拟器也能读回真实 DOM/xterm 数值。
  用法与"它不能替代什么"写在 `evidence/渲染与设置/本地测试台说明.md`。
- 每个功能点一个驱动文件（`t-settings.mjs` / `t-scroll.mjs` / `t-drawer.mjs` / `t-boot.mjs`），
  断言全是要读回来的事实（`term.options.fontSize`、computedStyle、`viewportY`、抽屉条目数、RPC 调用次数、`performance.now()`）。
