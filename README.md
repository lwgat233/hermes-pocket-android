# hermes-pocket — 项目归档

**这是什么**：安卓应用 **Hermes Pocket**（WebView + 原生 SSH 的移动终端外壳）的
**项目源码快照 + 可安装构件 + 全部测试存证**。

本文件夹是 `/vol1/1000/airesults/` 容器里的一个项目（容器索引见 `../README.md`）；
跨项目通用的问答在 `../qanda/android-dev.md`。

> 同级的 `20260916_235652_4b2d2c/` 不是本项目产物，未触碰。

## 目录结构

```
README.md     本文件：项目说明与索引
MANIFEST.txt  项目内逐文件清单（大小 + 构件/文档哈希）
apk/          可安装构件 + 构件哈希
docs/         三份交付文档（项目说明 / 缺陷修复报告 / 集成测试报告）
env/          构建/测试环境配方：Dockerfile（原样导出）+ emu.sh 原件 + 容器/镜像 inspect + 环境说明
evidence/     全部原始输出存证，按主题分 6 组
source/       项目源码快照（可直接构建）
tools/        测试工具 + 本次验收用的脚本
```

**归档约定**（以后新项目同样处理）：
① 环境配方（Dockerfile、脚本原件、`docker inspect`）原样存进 `env/` —— 脚本常把 Dockerfile 写进临时目录即删；
② 原始文件与脱敏后的派生文件分开存，原始件优先保留；
③ 源码快照必须能干净复现出交付构件的哈希。

## 源码快照（source/hermes-pocket/）

- 42 个文件 / 4.2M，约 5,400 行 Kotlin + JS（`app/` 应用、`bridge/` 调试用 Node 桥）
- **排除**：`build/`、`.gradle/`、`.git/`、`node_modules/`、`local.properties`（构建产物与本机路径）
- 构建：`gradle --no-daemon -Pkotlin.compiler.execution.strategy=in-process :app:assembleDebug`
  （依赖仓库走本机可达的镜像；`google()` 在此环境不可达）
- **脱敏**：假测试服务器（`tools/testssh2.mjs`）的默认测试口令、以及首轮探针里的测试私钥，
  已替换为占位符 —— 复现时用参数显式传入即可
- **不含**任何真实私钥、`master.key`、`known_hosts`、应用数据快照

## 怎么用

1. 装 `apk/hermes-pocket-debug.apk`。
2. 加主机：地址/端口/用户 + 公钥（可从应用里生成并一键装到服务器）或口令。
3. 建议远端跑 `tmux`：断了重连能回到原会话（设置里「重连后自动回到原会话」默认开）。
4. 想复现测试：用 `tools/tools-testssh2.mjs` 起假服务器，或照着 `tools/验收脚本/` 里的脚本
   用 CDP 连 debug 构件的 devtools socket 读真实页面状态。
