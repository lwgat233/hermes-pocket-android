## 2. 复验中发现的两个缺陷（**只有真机才暴露**，本地测试台永远测不到）

### 缺陷 A：断线之后点「连接」连不回去（卡在「传输未就绪」）

- **现象**：断开（网络掉线 / 远端重启 / 手动断开都会走到这个状态）之后，从「主机」卡片点「▶ 连接」，
  30 秒内状态一直是 `disconnected`，提示 `打开会话失败: 传输未就绪`；而「🔌 重新连接」那条路是好的。
- **根因**：`App.connect()` 直接 `rpc('session.open')`；传输层对象还在但 `alive === false`，
  `rpcRaw` 第一行就 `reject('传输未就绪')`。重开传输的动作只写在 `reconnectNow()` 里，两个入口行为不一致。
- **修法**（`assets/ui/app.js` `connect()`）：发 `session.open` 之前，若传输层不活就先 `transport.open()`。
- **验证**：修完后在设备上从 `disconnected` 点「连接」→ 1 秒内 `connected`（见证据第四批 `确保连接`）。

### 缺陷 B：Android 的 `JSONObject.quote()` 拼 python 字面量，把 `/` 写坏 → 读技能失败、回写内容会变形

- **现象**：设备上点技能行 → `读技能失败：读不到: [Errno 2] No such file or directory:
  '/home/lwgat/.hermes/skills\/hpk-verify-tmp\/SKILL.md'`（路径里出现了 `\/`）。
- **根因**：Android 的 org.json `JSONObject.quote()` 会把 `/` 转义成 `\/`（JSON 里合法，JSON 解码器会还原）。
  但它是被用来拼 **python 字符串字面量**的：python 不认 `\/` 这个转义，反斜杠原样留在字符串里 →
  远端拿到的路径是 `skills\/x\/SKILL.md`。同一处还会把 **base64 里的 `/`** 写坏（整篇回写的内容会变形）、
  以及带斜杠的模型名（如 `vendor/model`）写坏。
- **修法**（`Bridge.kt`）：新增 `pyStr()`（只转义 python 认的字符），把 4 处拼 python 字面量全部换掉；
  路径校验 `safeRel()` 同时会把带反斜杠的路径直接拒掉（这条本来就在，所以显示成「路径不允许」的那次是对的）。
- **验证**：修完后同一路径读到 `@@SIZE 343 / @@SHA 56a0baf… / base64 完整`；下载到手机的文件 sha256 与远端一致；
  回写成功且内容正确（含中文/emoji/斜杠）。本地侧 `tools/check_skill_py.py` 也复跑一遍（把 `Bridge.kt` 里脚本原样抽出跑）全通过。

## 3. 复验过程中踩到的一个**危险点**（已纠正，流程已改）

设备第一次连接时，App 按启动流程 attach 了远端**已存在的** tmux 会话 —— 那台机器上唯一的会话
正是**用户自己在用的 `hermes`**（Hermes CLI 就跑在里面），设备的终端于是显示/可能写入用户的真实会话。

- 这本身是需求第 6 条规定的**正确行为**（「有 tmux 就不管它、attach 它」），不是缺陷；
- 但对"本机自己就是远端"这种情形，设备复验必须**先把「进哪个会话」指到一次性会话**再连（本轮改成 `hpk-verify`）；
- 本轮只读了 xterm 缓冲区，**没有向该会话发送任何按键**；收尾时 App 内断开（App 永不 kill tmux），
  用户会话创建时间未变（Sep 16 23:18:43）。
- 已在 App 技能里记下这条操作纪律（见 §4）。

## 4. 本轮没有验到的（老实写清楚）

- **真手机（非模拟器）**：本轮用的是 x86_64 模拟器 + 软件渲染（swiftshader），
  启动耗时、字体度量、耗电行为与真机不同；触屏手势（双指缩放、长按菜单）本轮**没有**在设备上点过。
- **改模型（F-HERM-5）的写回**：设备上只做了只读确认（避免动用户的 `config.yaml`）；
  写回与还原的证据仍是本地测试台 + 把 `Bridge.kt` 里脚本原样抽出来跑。
- **断网/睡眠等真实故障路径**：缺陷 A 是"手动断开"触发的；真实掉线（射频断、进程被杀）没在设备上造过。
- **大文件过原生桥**：技能回写这条通道只试了 ~350 字节的文档；几十 KB 的 SKILL.md 没压过。
- **真远端 tmux 的"有就不管"只验了 attach 分支**：`没有 tmux 才建` 的分支本轮没造（怕影响用户会话）。
